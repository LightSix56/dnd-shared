# dnd-shared

Общая библиотека D&D 5e для двух сайтов: ИИ-мастер (`dnd-ai-master`) и лист персонажа (`dnd5e-character-sheet`).

## Что внутри
- `data/spells.json` — 525 заклинаний (dnd.su). У 502 есть поле `combat` с параметрами для боевого движка (SRD 5.1 и расширенные боевые заклинания), у остальных его нет.
- `src/index.js` — `SPELLS` и `findSpell(запрос)` (английское или русское название, id листа, прежний id мастера).
- `scripts/build-spells.py` — сборка `data/spells.json` из двух источников; запуск описан в начале файла.

## Совместимость
В листе героя заклинания хранятся по русскому названию, поэтому названия не меняются. Прежние id мастера (`spell_exp_N`, id SRD) сохранены в `legacyIds`, прежние английские названия — в `aliasesEn`.

## Подключение
`"dnd-shared": "github:LightSix56/dnd-shared#<хэш коммита>"` (закрепляем коммит; теги из окружения Claude запушить не удаётся)
